# SKILL: Weather & Travel Planner Development Standards

## 1. Core Rules & Constraints

- **Technology Stack:** Pure HTML5 (Semantic), CSS3 (Flexbox/Grid), and Vanilla JavaScript (No external frameworks/libraries).
- **Design Style:** Glassmorphism design system using `backdrop-filter: blur()`, semi-transparent backgrounds, subtle borders, and smooth glowing hover states.
- **Project Structure:** Organized strictly into dedicated folders:
  - `/css/` (External CSS stylesheets, e.g., `style.css`)
  - `/js/` (External JavaScript scripts, e.g., `script.js`)
  - `/images/` (Backgrounds, icons, and graphic assets)
  - `/video/` (Optional video assets)
- **Change Management:** Whenever a modification, addition, or refactoring is proposed, **always present options/alternatives** to the user and wait for confirmation before applying changes.
- **Planning Protocol:** **Always create and present a step-by-step implementation plan** before writing or modifying any code.
